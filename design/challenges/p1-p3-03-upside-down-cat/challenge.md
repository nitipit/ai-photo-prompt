# Challenge P1–P3–03: Cat Sleeping on the Ceiling

## Concept

An orange cat wearing blue pajamas sleeps peacefully on a bed attached to the
ceiling in a completely upside-down bedroom. Toys, a bookshelf, and a
moon-shaped lamp also appear above the room.

The visual joke is a cozy bedroom where the ceiling has become the floor.

## Core scoring anchors

- Orange cat sleeping
- Bed attached to the ceiling
- Clearly upside-down bedroom

## Optional details

- Blue pajamas
- Toys and bookshelf
- Moon-shaped lamp
- Hanging blanket
- Cozy night-time colors

## Example short prompt

> แมวนอนบนเตียงบนเพดานในห้องกลับหัว

## Evaluation notes

The player does not need to describe every upside-down object. The cat, the
bed, and the reversed room establish the main idea. A short prompt remains
valid when it communicates the visual twist clearly.

## Feedback focus

Praise recognition of the unusual room orientation. Suggest one supporting
detail only if the main idea is already present.
