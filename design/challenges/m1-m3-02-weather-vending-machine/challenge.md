# Challenge M1–M3–02: Weather Vending Machine

## Concept

On a rainy neon city street at night, a raccoon wearing a raincoat presses a
vending machine. Instead of a drink or snack, the machine dispenses glass
bottles containing tiny weather scenes: a glowing sun, a cloud, rain, and a
rainbow.

The visual joke is an ordinary vending machine selling bottled weather.

## Core scoring anchors

- Raccoon using a vending machine
- Vending machine dispensing weather bottles
- Tiny sun or weather inside a glass bottle
- Rainy neon city at night

## Optional details

- Raincoat
- Bottles containing clouds and rainbows
- Wet reflective street
- Abstract sign lights without text
- Glow from the bottles

## Example short prompt

> แรคคูนกดตู้ขายของในเมืองกลางคืน แล้วได้ขวดที่มีดวงอาทิตย์เล็ก ๆ อยู่ข้างใน

## Evaluation notes

This challenge rewards a clear surreal object relationship. The vending machine,
bottled weather, and rainy city establish the main idea; players do not need to
name every bottle or light reflection.

## Feedback focus

Praise the player for describing what the machine unusually sells. Suggest one
weather detail or atmosphere detail when the core concept is already clear.
