# Main Goal

Photo Prompt เป็นเกมบูธภาษาไทยสำหรับงานสัปดาห์วิทยาศาสตร์ โรงเรียนสาธิตเกษตร ให้เด็ก
ป.1–ม.6 เล่นคนละหนึ่งรอบอย่างรวดเร็ว โดยเขียนคำสั่งให้ AI
สร้างภาพตามภาพโจทย์ที่คัดเตรียมไว้ล่วงหน้า แล้วสนุกกับภาพที่ได้ คะแนน และ leaderboard
พร้อมค้นพบว่า prompt เป็นทักษะที่ต้องอาศัย การสังเกต การเข้าใจโจทย์ และการสั่งงาน AI ให้ชัดเจน
ประสบการณ์หลักควรรู้สึกเป็นเกมบูธแบบ scene-based สำหรับจอเดียว ไม่ใช่เว็บฟอร์มยาว ๆ
โดยให้ผู้เล่นเห็นทีละฉากที่ชัดเจน เล่นต่อเนื่อง และไม่ต้องเลื่อนหน้า
