# Booth Game

ทุกการตัดสินใจควรรักษาประสบการณ์เกมบูธที่เล่นเร็ว เข้าใจง่าย และสนุกทันที
เด็กแต่ละคนควรเริ่มเล่นได้โดยไม่ต้องอธิบายนาน เล่นจบในหนึ่งรอบ และออกจากเกม
พร้อมความรู้สึกว่าได้ลองท้าทาย AI จริง ๆ ไม่ใช่ทำแบบฝึกหัดยาว ๆ
ภาพโจทย์ควรเป็นชุดที่คัดเตรียมไว้ล่วงหน้า เพื่อให้รอบเล่นเร็ว คุมคุณภาพโจทย์ได้
และไม่ให้เด็กต้องรอการสร้างโจทย์สดระหว่างเล่น หน้ารอบเล่นควรให้ความรู้สึกเป็นฉากเกมบูธแบบ 16:9
สำหรับจอแล็ปท็อป โปรเจกเตอร์ หรือ kiosk มากกว่าเว็บฟอร์มทั่วไป โดยจัดภาพโจทย์ prompt ผลลัพธ์
คะแนน และ leaderboard ให้เหมาะกับการดูร่วมกันหน้าเครื่อง เกมควรแสดงทีละ scene ใน viewport
เดียวโดยไม่ต้องเลื่อนหน้า เพื่อให้เด็กเข้าใจว่าต้องทำอะไรต่อ และเพื่อให้คนคุมบูธ debug
แต่ละจังหวะได้ง่ายกว่าเว็บหน้าเดียวที่รวมทุกอย่างไว้พร้อมกัน
